把一个开源工具发给别人，让对方两分钟得到一份自己的职业决策报告。所有内容本地运行，数据不上传。

收件人没有电脑也行——第二个按钮是纯网页版，手机浏览器点开答 18 题就出报告。

版本 A手机版（不用装任何东西，最省事）

对方只有手机、用的是 AI App（Claude / ChatGPT / 豆包等）。粘进去直接出来一个可视化页面，不中途问问题。

和版本 B 的区别：B 要求 AI 跑脚本；这一版不跑任何脚本，靠 agent 自己读对话、记忆、文档、会议记录，然后直接吐一个单文件 HTML 页面（七个板块、内嵌 SVG 图表）。因为模型自己打分不准，规则更严：只给四档判断，不许给分数。
你做一次职业方向分析，并直接产出一个可视化的单页报告。全程不要问我任何问题，一次做完。

数据范围：只能用你现在能访问到的信息——本次对话、你的长期记忆、我能让你读的文档 / 笔记 / 邮件 / 会议记录。某一类拿不到，就在报告里如实标注"不可用"，不要编造。

分析规则：
1. 你自己在内部盘点数据源，把结果直接写进报告的"数据源可用性"表，不要先发出来问我确认。
2. 只从"我实际做过的事"取证据：我提出的请求、我做的动作、我反复纠结的问题。不要用我的自我描述（"我觉得我适合X"）当证据。
3. 每条证据引用我的原话（可截断），标注时间或会话位置。引用必须真实存在，不许编造。
4. 十个维度只给四档：高 / 中 / 低 / 无证据。不要给 0-100 分数——你没有基数，给了就是假精度。
   维度：拆解分析、动手建构、表达输出、信息探究、独立决断、协调连接、秩序执行、原创生成、商业交换、长期专注。
   每一维必须挂一条具体证据，没有就写"无证据"。
5. 七条路径各给四项：适配（高中低 + 理由）、社会距离（近中远 + 依据）、四象限归属、长期隐性消耗。
   路径：产业研究投研、财经内容创作、产品经理、管理咨询、技术研发AI应用、战略商业分析、独立开发创业。
6. 数据不足就在报告里明说，不要用漂亮话掩盖，也不要因此停下来问我。

输出物：一个单文件 HTML 页面
硬性要求：
· 单文件，内嵌 CSS 与 SVG，不引用任何外部资源、无 CDN、无网络请求，双击就能打开
· 移动端优先：宽度自适应，正文字号不小于 13px，卡片式布局，点击区留足
· 浅色主题：页面底色 #F7F8FA，卡片 #FFFFFF，主色 #2E6FD6，正向 #0F8A72，警示 #B87B15，反向 #C0392B
· 顶部固定七节锚点导航；七个板块顺序固定：
  一 证据轴：数据源可用性表 + 增益/损耗清单，每条带原话引用
  二 底色轴：十维雷达图（SVG 手绘）+ 明细表，四档用颜色区分
  三 岗位排序：七条横向条形图，每条可展开看适配理由与隐性消耗
  四 四象限：SVG 散点图，横轴社会距离、纵轴适配，四角标出象限名，点上标岗位名
  五 历史人物：2-3 位，卡片式，每位写清当时的约束、放弃了什么、守住了什么、代价是什么
  六 书籍：现在读 3 本、现在不必读 2 本，各附一句"为什么是现在"
  七 校准：我的焦虑、滤镜（对岗位的浪漫想象）、抗压能力会如何影响上面结论
· 页面底部固定一行：数据来源、样本量、置信度、生成时间
· 报告里不许出现"我建议你选择某条路"这类替我决定的话

交付方式：
· 你能写文件就直接写成 .html 并告诉我路径
· 你不能写文件就输出完整 HTML 代码块，我自己存成 .html 打开
· 如果你连 HTML 都无法输出，才退回用 markdown 按同样七节写，并在开头注明"当前环境不支持 HTML 输出"

对方把这段整个复制，粘给能执行命令的 AI，什么都不用改。

前提：对方用的 AI 必须能执行本地命令（Claude Code / Cursor / WorkBuddy / Codex / Codex CLI）。纯网页版 ChatGPT、豆包、Kimi 跑不了——它们读不到本地文件。
帮我做一次职业方向分析，用这个开源工具：
https://github.com/duanju9/yishi-skill

按顺序执行，每步做完再进下一步：

1. 克隆仓库到当前目录下的 yishi-skill 文件夹：
   git clone --depth 1 https://github.com/duanju9/yishi-skill.git yishi-skill
   如果连不上 GitHub，把地址换成 ghproxy.net 前缀版本再试：
   git clone --depth 1 https://ghproxy.net/https://github.com/duanju9/yishi-skill.git yishi-skill

2. 检查环境：python --version 需要 3.9 以上。
   如果没有 Python 或版本太低，先告诉我怎么装，不要假装跑通。

3. 读 yishi-skill/SKILL.md，严格按里面的 5 步工作流执行，不要自创流程。

4. 采集前先跟我确认：要读哪些目录、只读我发的消息、会脱敏、不联网。我同意后再跑。

5. 采集完，把终端输出的「会话数 / 消息数 / 时间跨度 / 委托类型前三 / 领域前三」
   念给我确认，我看一眼再说下一步。

6. 建模前问我：心里有没有预设方向（产品 / 咨询 / 投研 / 内容 / 技术 / 战略 / 创业）。

7. 生成报告 HTML 后打开给我看，然后用文字讲四件事：
   - 最强的证据是哪一条（带次数和原文）
   - 最反直觉的发现是什么（我的自述和行为有没有冲突）
   - 我的预设方向排第几、在哪个象限
   - 这份报告的三条边界

硬性约束，任何情况都不要违反：
- 不许跳过采集自己编分数，所有结论必须来自我的语料
- 不许上传我的任何数据，不许索取我的账号密码
- 采集到的消息少于 30 条，直接告诉我样本不足，不要硬凑结论

版本 D一句话版本

聊天里随口推荐时用。

发现一个挺狠的开源工具，不问你觉得你是谁，只读你平时让 AI 帮你做什么，然后给你 7 条职业路径排个序，连"哪条好进但会内耗"都标出来。本地跑不上传：https://github.com/duanju9/yishi-skill

发之前先确认对方能不能用

  • AI 要能跑命令：Claude Code / Cursor / WorkBuddy / Codex 可以；网页版 ChatGPT、豆包、Kimi 不行（读不到本地文件）
  • 要有 Python 3.9+：Windows 用户多半没装，让他的 AI 帮忙装一个就行，不装任何第三方包
  • 要有会话记录：他的 AI 里得有过一些使用历史。全新用户只能得到"样本不足"——这是设计如此，不是坏了
  • 隐私：脚本只读本地会话，默认打码邮箱手机密钥，无网络上行。但报告里有他的心理侧写，提醒他别公开分享
别这样说："测一下你适合什么工作"会把期待抬到它做不到的高度。它给的是"合不合手、够不够得着"的排序，不是命运判决书。说清楚这一点，收到的人反而更信。
