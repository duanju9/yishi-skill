# 模型说明与调参

## 为什么是三维 + 两层

单看"人和岗位合不合"，只能得出"理论上适合"。现实里大量错配不是能力问题，是**够不着**：不知道真实工作长什么样、没有人带、进不去那个圈子。所以需要一个独立的社会属性层，把"适合"和"可达"分开算，再合成。

| 轴 | 回答的问题 | 数据来源 |
|---|---|---|
| 生态轴（X） | 这个岗位实际在做什么、代价是什么、门槛在哪 | `assets/library.json: roles`，人工整理 |
| 底色轴（Y） | 我在什么动作上会获得能量、在什么地方被消耗 | 用户语料 + 10 维映射 |
| 时序轴（Z） | 我的轨迹是否连续、未来路径是否可延展 | 语料的时间分布、跨度、活跃月份 |
| 加权层 | 我离这个圈子多远 | 岗位开放度 + 语料共现 |
| 校准层 | 我现在的判断被什么干扰 | 焦虑/滤镜/抗压关键词 |

## 10 维动作倾向

| 维度 | 含义 | 主要来源 | 证据权重 |
|---|---|---|---|
| analyze 拆解分析 | 把复杂对象拆成可验证结构 | 分析拆解任务 + 投研/管理领域 | 1.0 |
| build 动手建构 | 做成可运行可交付的东西 | 编码实现任务 + 技术领域 | 1.0 |
| express 表达输出 | 把理解变成别人读得懂的文本 | 写作文案任务 + 内容领域 | 1.0 |
| explore 信息探究 | 主动搜寻比对验证 | 信息查询/学习理解 | 1.0 |
| create 原创生成 | 从无到有产出新方案 | 创意生成 + 内容领域 | 1.0 |
| decide 独立决断 | 信息不全时自己拍板 | 决策求助占比（反向） | 0.50 |
| connect 协调连接 | 推动他人、对齐利益 | 人际情感/组织管理领域 | 0.60 |
| trade 商业交换 | 对成本收益定价敏感 | 商业创业领域 | 0.55 |
| operate 秩序执行 | 把流程细节稳定做完 | 事务操作任务 | 0.45 |
| focus 长期专注 | 同一件事持续数月 | 时间跨度 + 活跃月份 | 0.60 |

**为什么后五个降权**：让 AI 帮忙协调关系、处理琐事、算账、拍板，本身就是"外包"行为。一个人可能极擅长这些，只是不需要 AI 帮。把它按满分权重算，会系统性低估"不爱指挥 AI 干活"的人。降权不是忽略，是承认证据更弱。

## 从计数到 0-100

```
raw   = 任务命中数 + 0.35~0.6 × 领域命中数
share = raw / 总消息数
score = 100 × (1 - e^(-share/0.15))
```

用占比而非绝对计数，是因为不同用户总量差一个量级（有人 50 条、有人 5000 条），绝对阈值不可移植。饱和函数保证"占比 15% → 63 分、30% → 86 分"，避免高频用户所有维度满分（这是 v0.1 的真实 bug）。

`evidence-rules.md` 里的门槛决定 `known`：`raw ≥ 8` 才算有证据。

## 适配分：非对称匹配

```
if 你 < 需求: match = 100 - (需求 - 你)          # 不足是硬伤，全额扣
if 你 ≥ 需求: match = 100 - (你 - 需求) × 0.55   # 充足是冗余，打五五折
适配 = Σ(需求 × 维度权重 × match) / Σ(需求 × 维度权重)
```

再加两道修正：

1. **强项闲废惩罚**：岗位需求 ≤55 而你 ≥75 的维度，每条扣 2.5。这是"内耗"的量化来源——不是你不适合产品岗，是产品岗用不上你的拆解力。
2. **覆盖率收缩**：`适配 = 60 + (原始分 - 60) × (0.55 + 0.45 × 覆盖率)`。证据越少越向中性回归，避免用 3 个维度推出 95 分。

## 社会距离

```
社会距离 = min(100, 岗位开放度 + 共现加成)
共现加成 = min(12, 2 × 「岗位关键词 + 人脉词」同句出现次数)
```

- 岗位开放度是人工估计（投研 66、内容 84、产品 74、咨询 41、技术 71、战略 59、创业 75），代表"外部人进入这个岗位的结构性难度"，不是"你的关系"。
- 共现加成是个人修正：语料里既提到这个岗位、又提到学长/前辈/内推/认识的人，说明用户至少有信息入口。
- 置信度按岗位提及次数分级：≥8 高、≥3 中、否则低。低置信度时，滤镜重的用户会对该岗位打折。

**明确局限**：没提过不等于没有，提过也不等于能内推。这个分数只能当"信息入口的粗略指示"。

## 扰动层

| 因子 | 计算 | 作用 |
|---|---|---|
| 焦虑 | 焦虑类词频 × 300，上限 100 | 每 +20 分，社会距离权重 +0.024（更保守，更想找有人带路的路） |
| 滤镜 | "听说/网上说/理想/羡慕"类词频 × 260 | ≥55 时，对社会距离置信度低的岗位扣 fit×0.08 |
| 抗压 | focus×0.6 + 跨度/3 | <40 时，对"高潜力高难度"象限额外扣分 |

权重公式：`社会权重 = 0.45 + 焦虑/100 × 0.12`，适配权重取余。基准是 45% 社会距离，焦虑拉满也只到 57%，**扰动只微调，不推翻骨架**。

## 调参指南

想改模型时，优先动这三个地方，不要动公式结构：

| 想改什么 | 改哪里 | 注意 |
|---|---|---|
| 岗位需求向量 | `library.json: roles[].demand` | 10 个值都在 0-100，改完跑一次看排序是否仍合理 |
| 关键词表 | `score.py: TASK_TYPES / DOMAINS` | 加词比改权重安全，先用新词跑一遍看命中量 |
| 象限分界 | `score.py: quad`（60）与 `fit_mid`（中位数） | 横轴 60 有绝对含义，不建议改；纵轴用中位数自适应 |

不建议做的事：为了"结果好看"去调阈值。一旦开始调，这个工具就退化成星座运势。
